    rules

    Slap the pile the instant the top cards match a pattern. Fastest correct slap takes the pile; a wrong slap burns a card to the bottom.

    Card values — A = 1 · J = 12 · Q = 11 · K = 13 · rest face value.

    • square — digits of the last 2+ cards concatenate to a perfect square (≥2 digits). 12,1 → "121" = 11²
    • cube — same, a perfect cube. 2,7 → "27" = 3³
    • arithmetic — top 3 are an arithmetic sequence, either direction. 2,4,6 · 5,5,5
    • geometric — top 3 are a geometric sequence. 2,4,8
    • fibonacci (mod 12) — each card is the previous two summed (wrapping at 12); run length set in settings. 2,3,5
